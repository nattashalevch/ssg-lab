# Конвейер обработки экспериментальных данных

## 1. Общая схема

В практической части лабораторной работы реализован конвейер автоматической обработки данных и формирования статического веб-сайта. Его задача — преобразовать исходные данные в графические и табличные результаты, а затем включить их в документацию.

Конвейер состоит из нескольких последовательных этапов:

1. Хранение исходных данных в CSV-файле.
2. Обработка данных с помощью Python.
3. Генерация графика.
4. Формирование сводной таблицы.
5. Включение материалов в сайт MkDocs.
6. Сборка статического сайта.

## 2. Структура проекта

Проект организован следующим образом:

```text
ssg-lab/
├── data/
│   └── measurements.csv
├── docs/
│   ├── index.md
│   ├── research.md
│   ├── methodology.md
│   ├── visualization.md
│   ├── results.md
│   └── images/
│       └── engagement.png
├── scripts/
│   ├── analyze.py
│   ├── plot.py
│   └── summary.py
├── mkdocs.yml
├── requirements.txt
├── Makefile
└── .gitignore
```

Структура разделяет исходные данные, программные скрипты, документацию и конфигурационные файлы, что упрощает поддержку и дальнейшее развитие проекта.

## 3. Исходные данные

Входные данные хранятся в файле `data/measurements.csv`.

Файл содержит показатели двух условных групп, представленные по неделям наблюдения. Используются следующие поля:

- `week` — номер недели;
- `group` — название группы;
- `engagement_score` — показатель вовлечённости;
- `task_completion` — показатель выполнения заданий;
- `interactions` — количество взаимодействий.

CSV выбран как простой, переносимый формат, который поддерживается Python и многими инструментами анализа данных.

Данные являются искусственными и предназначены для демонстрации работы конвейера.

## 4. Обработка данных

Для обработки данных используются Python-скрипты, расположенные в каталоге `scripts/`.

Скрипт `analyze.py` рассчитывает средние значения основных показателей для контрольной и геймифицированной групп.

Скрипт `plot.py` считывает исходные данные, формирует график динамики вовлечённости и сохраняет изображение в каталог `docs/images/`.

Скрипт `summary.py` формирует сводную таблицу результатов в формате Markdown и сохраняет её в файл `docs/results.md`.

Таким образом, результаты обработки автоматически становятся частью документации сайта.

## 5. Автоматизация с помощью Makefile

Для упрощения запуска отдельных этапов используется Makefile.

Основные команды проекта:

| Команда | Назначение |
|---|---|
| `make analyze` | Расчёт показателей |
| `make plot` | Построение графика |
| `make summary` | Генерация сводной таблицы |
| `make generate` | Генерация графика и таблицы |
| `make build` | Генерация материалов и сборка сайта |
| `make serve` | Запуск локального сервера |

Команда `make generate` позволяет повторно сформировать график и таблицу на основе актуального файла CSV.

Команда `make build` выполняет генерацию материалов и сборку статического сайта с проверкой строгого режима MkDocs.

## 6. Воспроизводимость

Воспроизводимость обеспечивается использованием исходного CSV-файла, Python-скриптов и зафиксированных зависимостей в `requirements.txt`.

При изменении исходных данных пользователь может повторно запустить генерацию результатов. График и сводная таблица будут обновлены, после чего сайт можно собрать заново.

Такой подход снижает количество ручных операций и вероятность ошибок при обновлении результатов.

## 7. Вывод

Реализованный конвейер связывает обработку данных и публикацию результатов исследования. Исходные данные преобразуются в график и сводную таблицу, которые включаются в статический сайт.

Использование Python, Makefile и MkDocs позволяет автоматизировать повторяющиеся действия, поддерживать структуру проекта и обеспечить более воспроизводимый процесс публикации исследовательских материалов.
