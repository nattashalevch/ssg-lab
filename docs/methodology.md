# Методика эксперимента

## 1. Цель эксперимента

Цель эксперимента — изучить влияние элементов геймификации и интерактивной визуализации на вовлечённость студентов в учебный процесс. Работа направлена на демонстрацию способов обработки учебных показателей, анализа динамики и публикации результатов с использованием генератора статических сайтов.

## 2. Организация эксперимента

Для демонстрации анализа сформированы две условные группы:

- **Контрольная группа** — учебный процесс без дополнительных игровых элементов.
- **Геймифицированная группа** — модель учебного процесса с использованием игровых элементов, таких как баллы, прогресс, задания и обратная связь.

Данные сформированы искусственно и используются исключительно для тестирования программного конвейера обработки, визуализации и публикации результатов. Они не являются результатами реального исследования студентов.

## 3. Исследуемые показатели

В эксперименте используются следующие показатели:

| Показатель | Описание |
|---|---|
| Engagement score | Условная оценка вовлечённости |
| Task completion | Доля выполненных учебных заданий |
| Interactions | Количество взаимодействий с учебной платформой |
| Week | Номер учебной недели |
| Group | Тип экспериментальной группы |

Показатели представлены в виде числовых значений, что позволяет применять методы статистической обработки и визуализации.

## 4. Этапы исследования

Экспериментальный конвейер состоит из следующих этапов:

1. Подготовка исходного файла с данными в формате CSV.
2. Чтение и обработка данных средствами Python.
3. Расчёт средних значений показателей для каждой группы.
4. Построение графиков динамики вовлечённости.
5. Автоматическое формирование таблиц результатов.
6. Включение полученных материалов в сайт MkDocs.
7. Сборка статического сайта и проверка корректности документации.

## 5. Методы анализа

Для анализа используется сравнение средних значений показателей контрольной и геймифицированной групп.

Дополнительно рассматривается динамика вовлечённости по учебным неделям. Графическое представление позволяет оценить изменение показателя во времени и визуально сравнить группы.

В рамках практической реализации используется Python и библиотеки обработки данных и визуализации.

## 6. Ограничения эксперимента

Основным ограничением является использование искусственно сформированных данных. Полученные значения не позволяют делать выводы о реальном поведении студентов или подтверждать эффективность геймификации в образовательной среде.

Эксперимент демонстрирует техническую реализацию обработки данных, построение визуализаций и автоматизированную публикацию научных материалов.

## 7. Вывод

Разработанная методика позволяет организовать последовательную обработку условных экспериментальных данных от исходного CSV-файла до публикации итоговых таблиц и графиков на статическом сайте. Такой подход упрощает повторное выполнение анализа, обновление данных и подготовку исследовательских материалов.
