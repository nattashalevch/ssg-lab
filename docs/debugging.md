# Отладка и устранение ошибок

## 1. Назначение раздела

В ходе разработки статического сайта возникали технические затруднения, связанные с настройкой окружения, конфигурацией MkDocs и выполнением команд в терминале.

В данном разделе приведены обнаруженные проблемы, способы их проверки и решения.

## 2. Обнаруженные проблемы

| № | Проблема | Возможная причина | Решение |
|---|---|---|---|
| 1 | Команда Python не распознавалась во второй вкладке терминала | Виртуальное окружение проекта не было активировано | Перейти в каталог проекта и выполнить `source .venv/bin/activate` |
| 2 | Страница не отображалась в меню навигации | Ошибка в названии или пути файла в конфигурации `mkdocs.yml` | Проверить соответствие пути фактическому имени файла и исправить блок `nav` |
| 3 | Терминал отображал приглашение `dquote>` и не выполнял новые команды | При вставке большого блока команд осталась незакрытая двойная кавычка | Нажать `Ctrl+C`, чтобы отменить незавершённый ввод, и повторить команды небольшими частями |

## 3. Проверка после исправлений

После устранения проблем были выполнены следующие проверки:

- повторная активация виртуального окружения;
- проверка структуры файлов проекта;
- проверка конфигурации навигации MkDocs;
- открытие созданных страниц в браузере;
- запуск команды `make build`.

Итоговая сборка завершилась успешно. MkDocs сформировал сайт в каталоге `site` за 0,89 секунды.

## 4. Вывод

В ходе разработки были рассмотрены и устранены проблемы, связанные с работой виртуального окружения, конфигурацией навигации и вводом команд в терминале.

Проверка проекта после исправлений подтвердила корректность структуры документации и возможность успешной сборки статического сайта.
